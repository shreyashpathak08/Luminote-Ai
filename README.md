# Luminote AI ✦

An elite, student-focused AI study assistant built with Flask, modern glassmorphism UI, and context-aware RAG (Retrieval-Augmented Generation) capabilities.

## ✨ Key Features

* **Cinematic God-Tier UI:** Built with hardware-accelerated CSS animations, Conic-gradient laser orbit borders, and custom ambient neon bloom effects.
* **Context-Aware Study Tools:** Seamlessly upload study notes (.pdf) or index public YouTube lectures to query your materials instantly.
* **Dynamic AI Personas:** Switch effortlessly between specialized learning modes (*Explain Like I'm 5, Exam Crunch, Standard Learner*).
* **Interactive Study Deck Studio:** Automatically extracts high-yield flashcards from your study materials with one-click Anki/Quizlet CSV exports.
* **The "World Eater" Easter Egg:** Hover over the central spark logo for 5 seconds to trigger a custom cinematic full-screen expansion micro-interaction!

## 🚀 Tech Stack

* **Backend:** Python, Flask, Google GenAI SDK, ChromaDB
* **Frontend:** HTML5, Modern CSS3 (Variables, Grid, Keyframes), Vanilla JavaScript
